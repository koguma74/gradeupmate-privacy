앱에서 직접 삭제하기

등급업패밀리(부모용) 앱에서 언제든지 직접 계정을 삭제할 수 있습니다.

  1. 등급업패밀리 앱을 실행하고 로그인합니다.
  2. 설정 → 앱 정보 화면으로 이동합니다.
  3. 계정 → 계정 삭제를 선택합니다.
  4. 본인 확인을 위해 현재 비밀번호를 입력합니다.
  5. 안내를 확인한 뒤 계정 영구 삭제를 누릅니다.
삭제는 즉시 처리되며 되돌릴 수 없습니다. 삭제 후에는 같은 이메일로 다시 가입하더라도 이전 데이터를 복구할 수 없습니다.

앱에 접근할 수 없거나 앱을 이미 삭제하신 경우, 아래 주소로 삭제를 요청하실 수 있습니다.

  • 받는 사람: koguma74@gmail.com

  • 본문에 포함할 내용: 가입 시 사용한 이메일 주소, 앱 이름(등급업패밀리 또는 등급업메이트)
본인 확인을 위해 가입 이메일 주소에서 보내주셔야 합니다. 요청을 접수한 날로부터 영업일 기준 14일 이내에 처리하고 결과를 회신합니다.

구분 항목 처리

AI 기능 기록 AI 학습 상담 내역, AI 리포트, 기능 사용 횟수 즉시 삭제

삭제 후 별도로 보관되는 데이터는 없습니다. 다만 서버 운영 기록(접속 로그 등)은 관련 법령에서 정한 기간 동안 보관될 수 있으며, 이 기록에는 학습 내용이나 개인 식별 정보가 포함되지 않습니다.

자녀용 앱(등급업메이트) 이용자

자녀용 앱은 별도의 계정을 만들지 않으며, 부모 계정에 연동되는 방식으로 동작합니다. 따라서 다음과 같이 처리됩니다.

  • 부모 계정을 삭제하면 연동된 자녀의 학습 기록과 사용 기록도 함께 삭제됩니다.
  • 자녀 기기에서 연동만 해제하려면 자녀용 앱에서 연동 해제를 실행하면 됩니다. 이 경우 기기에 저장된 학습 기록은 앱을 삭제하면 함께 제거됩니다.
  • 단독 사용(게스트) 모드로 이용한 경우에는 서버에 저장되는 데이터가 없으며, 앱을 삭제하면 모든 기록이 사라집니다.
